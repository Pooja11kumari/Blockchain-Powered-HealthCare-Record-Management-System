# Blockchain-Powered-HealthCare-Record-Management-System

## A decentralized healthcare record management system built on the Solana blockchain. This platform allows secure, transparent, and tamper-proof storage and sharing of patient health records using smart contracts and IPFS.

 This text starts from the left margin.


## Project Overview

Traditional healthcare record systems are centralized and prone to data breaches. This project leverages blockchain technology to provide a secure, decentralized alternative. Patient records are encrypted, stored on IPFS, and managed via Solana smart contracts, ensuring only authorized access.


## Features

<ul style="margin-left:0;">
  <li>Decentralized Storage: Patient records are securely stored on IPFS.</li>
  <li>Smart Contracts: Access control and data validation on Solana blockchain.</li>
  <li>Patient Privacy: Only authorized doctors or hospitals can access records.</li>
  <li>Audit Trail: All changes are on the blockchain for transparency.</li>
  <li>Full-Stack Web Interface: User-friendly interface for patients and healthcare providers.</li>
</ul>
